# Лабораторная работа 5. Защита исследовательского проекта: разметка музыкального каталога по типу фронт-вокала

Тема ВКР: *Разработка системы автоматической разметки музыкального каталога по типу фронт-вокала для задач поиска и рекомендаций.*
Итоговый проект объединяет [ЛР1](https://github.com/kater1nart/lab1_vocal_llm) (LLM/VLM), [ЛР2](https://github.com/kater1nart/lab2_multimodal_vocal) (мультимодальность),
[ЛР3](https://github.com/kater1nart/lab3_marl_vocal) (MARL) и [ЛР4](https://github.com/kater1nart/lab4_optim_vocal) (оптимизация).

## Итоговая система (`src/pipeline.py`)
1. приём и валидация трека (метаданные + 10 с аудио, 16 кГц);
2. LLM-модуль — исключён из решений (VLM ≤ 0.24 Macro-F1);
3. три эксперта: текст (TF-IDF), временной ряд звука, спектрограмма (CLIP) → среднее вероятностей (Macro-F1 0.748 на MTAT test);
4. маршрутизация: автометка при уверенности ≥ τ, иначе модератор (правило лучше 8 MARL-алгоритмов);
5. контроллер риска: бюджет модерации, журнал JSONL, объяснение (голоса модальностей, согласие, причина).

При τ под SLA 10% (подбор на val): **44% треков размечаются автоматически с ошибкой 8.4%** (MTAT test); на новом каталоге Jamendo — 14.8% ошибок, нужна перекалибровка.
