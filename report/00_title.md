# Лабораторная работа 5. Защита исследовательского проекта по теме ВКР

**Дисциплина:** Прикладные задачи машинного обучения

**Тема ВКР:** Разработка системы автоматической разметки музыкального каталога по типу фронт-вокала для задач поиска и рекомендаций

**Проект:** Доказательная система разметки музыкального каталога по типу фронт-вокала с мультимодальными экспертами и модератором в контуре

**Выполнила:** Таарачева Екатерина Вадимовна (индивидуально)

**Краткий итог.** Результаты ЛР1–4 объединены в одну систему и одну экспериментальную главу.
- **VLM без обучения** определяют тип вокала по спектрограмме на уровне угадывания (Macro-F1 ≤ 0,24), поэтому LLM-модуль исключён из контура решений.
- **Слияние трёх модальностей** — текста метаданных, временного ряда звука и спектрограммы — даёт значимый прирост на основном каталоге (+0,079, p = 0,0002), но не переносится на новый каталог.
- **Маршрутизация «автометка / модератор»:** простое централизованное правило выигрывает у всех 8 MARL-алгоритмов.
- **Оптимизаторы:** выбор определяется архитектурой, а случайность обучения сопоставима с разницей между методами.

Итоговая система при пороге под требование «ошибок не больше 10%» размечает автоматически 44% треков с ошибкой 8,4%. На новом каталоге требуется перекалибровка.
